# RepoLaunch 🔎

**The search engine of trusted open-source repos.**

Search anything you want to build — "animation", "AI chatbot", "booking app" — and get curated, **verified** GitHub repositories for that niche, each with a complete blueprint: what it is, how to set it up, where to use it, and **how to earn money with it**.

> 400M repos on GitHub. ~98% are junk. We map every niche to the best ones — verified, explained, monetized.

## Quick start

```bash
npm install
npm run dev        # http://localhost:3000
npm run sync:stars # refresh live star counts from the GitHub API
```

## What's inside

- **Search-first UX** — fuzzy search across 20 categories and 120+ niches
- **Trust system** — every repo verified: 500+ stars, maintained, documented, license checked
- **License intelligence** — green Safe (MIT/Apache/BSD) vs red Warning (GPL/AGPL) with plain-English commercial notes
- **Blueprints** — setup steps from official docs, copy-paste config files, 3 monetization playbooks per repo
- **Nightly star sync** — GitHub Action keeps repo facts machine-verified (`scripts/sync-stars.mjs`)
- **Gen Z aesthetic** — dark theme, animated gradients, glassmorphism
